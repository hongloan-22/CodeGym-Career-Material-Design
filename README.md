# CodeGym Career — Material Design Landing Page

Bài thực hành xây dựng lại landing page theo phong cách Material Design bằng Bootstrap 4 và MDBootstrap 4.19.1.

## Cấu trúc
- `index.html`: cấu trúc trang, navbar, hero, lợi ích, lộ trình, khóa học, dự án, biểu mẫu và footer.
- `style.css`: màu sắc, khoảng cách, card, hiệu ứng và responsive.
- `script.js`: năm hiện tại, nút lên đầu trang, menu di động và kiểm tra biểu mẫu demo.

## Chạy trên máy
1. Giải nén thư mục.
2. Mở `index.html` bằng Chrome hoặc Edge. Không cần cài Node.js.
3. Cần có kết nối Internet để tải Bootstrap, MDBootstrap, jQuery, Font Awesome và Google Fonts từ CDN.
4. Thử thu nhỏ cửa sổ trình duyệt để kiểm tra giao diện responsive.

## Đưa lên GitHub
1. Tạo repository trên GitHub.
2. Chọn **Add file → Upload files**.
3. Tải lên `index.html`, `style.css`, `script.js`, `README.md`.
4. Chọn **Commit changes**.
5. Nếu cần website công khai: vào **Settings → Pages**, chọn nhánh `main` và thư mục `/(root)`, lưu lại. Chờ GitHub Pages xuất bản rồi mở URL được cung cấp.

## Lưu ý về nội dung
Đây là bản dựng phục vụ bài tập, dùng nội dung tóm lược và các ví dụ minh họa dựa trên trang CodeGym Career. Một số khối (lộ trình, dự án, thẻ chương trình) được diễn giải để phục vụ bố cục; ảnh học viên/đánh giá thật chưa được đưa vào. Biểu mẫu đăng ký chỉ kiểm tra dữ liệu tại trình duyệt, chưa kết nối hệ thống nhận đăng ký. Hãy kiểm tra lại thông tin trên website chính thức trước khi nộp và ghi rõ đây là giao diện thực hành.
